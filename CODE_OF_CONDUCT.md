# Code of conduct

PulseOps should be a useful and welcoming place to discuss software engineering.

## Expected behaviour

- Be respectful and constructive.
- Critique ideas and code, not people.
- Assume good intent, but be clear when behaviour causes harm.
- Keep discussions relevant to the project.
- Help newcomers understand the reasoning behind decisions rather than dismissing questions.

## Unacceptable behaviour

Harassment, discrimination, personal attacks, threats, deliberate disruption, or publishing another person's private information without permission are not acceptable.

## Enforcement

Project maintainers may edit or remove comments, close discussions, reject contributions, or restrict participation when behaviour conflicts with these expectations.

If you need to report conduct privately, contact the repository owner through their GitHub profile rather than opening a public issue.
